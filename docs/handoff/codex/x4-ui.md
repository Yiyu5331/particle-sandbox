# X4 UI 框架与通用界面

2026-11-20，Codex。工作树位于 `particle-sandbox-x4-ui`，分支 `codex/x4-ui` 来自 `main` 的 `0f4bd8e`。

## 当前状态

通用组件、双语词表、加载页、实时演示主菜单、五个模式入口、图鉴、设置、暂停、结算和 HUD 均已接入单文件。组件接口、测试命令、键盘操作和 HUD 数据例子见 [UI.md](../../UI.md)。

## 实现决策

- 主菜单使用独立的演示模式和世界；通过现有管理器切换，返回沙盒保留原局。降低动态效果的系统偏好会暂停演示。
- 图鉴展示引擎公开的材料。进度摘要使用独立的零值 mock，按任务约定等待 X2 合并。
- UI 在模式注册时适配结构化 HUD，由原管理器按既有节奏采样。结算读取真实 outcome 消息及可选 stats。占位玩法的胜负由测试替身触发。
- 引擎热身目前是一次同步调用。加载页显示四个真实完成阶段，细分热身回调和正式 HUD 类型已登记于 [API_REQUESTS.md](../../API_REQUESTS.md)。
- 中文为默认语言，英文在运行时切换。用户槽名、文件名保留原文；开发自测报告保留用例原名。happy-dom、Acorn 仅用于测试，浏览器单文件独立运行。
