# 交接 · X5.1 解谜关卡格式

## 当前目标和状态

独立工作树分支 `codex/x5.1-format` 已更新到 C3 的 PR #5 合并后的 `origin/main`。关卡格式仍为 v1。

## 已完成

- 定时命令、编辑器时间轴、固定环境、通用连续条件、燃烧计数、统计区和区域材料白名单。
- 双语关名、章名、目标和三级提示。选关优先读关卡字段，旧例沿用原词表。查看提示的级数随本局存档、重试及重置保留，星级依旧由用料和步数决定。
- 构建和命令行校验共用递归目录发现。示例的解锁顺序由 `levels/order.json` 保持，C3 目录沿用 `meta.json` 的顺序。
- C3 文本迁移工具及测试。正式迁移在 PR #5 合并后执行，给 30 关添加了双语文字和三级提示，删除全局词表中的 66 条 C3 临时翻译，C3 测试改为直接验证关卡字段。C3 生成器重用同一转换逻辑。

## 决策和原因

- 第 N 步事件在该步模拟前、同一帧玩家笔画后执行。同一步数组顺序保留。引擎日志记录全部成功命令，关卡参考和进度只保存玩家笔画，由关卡重新生成事件。
- 旧 `name`、`chapter`、`hint` 字符串保留，迁移添加本地化字段。这样 C3 的旧关卡标识及已有工具仍能工作。
- C0 回放会提前应用全部区域。含初始笔画和区域绘制限制的关卡会用公开存档命令记录搭建结果，使引擎回放中的初始笔画不受后续规则过滤。

## 验证

- 3 个示例及 C3 分支上的 30 个原始文件通过双播三星验证，正式迁移只新增文本字段。
- 迁移后的 33 关再通过双播三星验证。C3 生成器重建后，迁移预览无待更新文件。
- 浏览器创建带定时放水事件的实时关，导出和载入后均第 13 步三星。模式存档恢复、引擎回放和实玩世界哈希一致。
- Node 全量回归、构建、45 项完整黄金快照、Chrome 自测 133 项和 Playwright 6 项均通过。
