# X5 物理解谜

2026-11-20，Codex。分支 `codex/x5-puzzle` 从 `main` 的 `0f4bd8e` 建立，使用独立工作树。

## 当前目标与完成项

- JSON 关卡、JSON Schema、命名区域、预算、组合条件、失败和星级标准已实现。浏览器与 Node 通过同一会话执行命令和判定。
- 规划型和实时型支持选关、重试、重置、记录与恢复。编辑器支持矩形地形、三种区域、配置、录制、双播验证、导出及载入。
- 三个示例各自以参考解取得三星，空解均失败。玩法和制作流程见 [PUZZLE.md](../../PUZZLE.md)。
- PR 与推送工作流包含单文件构建、无头测试和 `node tools/levels.mjs validate`。自定义 JSON 也可单独传给 CLI。

## 决策与原因

- X2、X4 均未合入此分支。选关使用页内最高星数 mock，界面采用原生表单。试玩自制关不会解锁官方关卡。
- 准确结算需每步检查条件。管理器在模式自行暂停时立即检查 outcome，剩余帧内子步会停止，避免画面多跑一步。预算助手同时尊重每种材料的余额与调用方给出的总额上限。
- 参考解法只记录相对步数和玩家笔画；关卡的初始化单独执行。重放会重新检查白名单、区域、预算和所有目标。无需新增引擎接口。
- 浏览器自测曾在 369×200 的旧电火花重力断言失败。已在干净 main 上得到同样的四向数值。用例现在逐步跟踪初始火花的位置及种子，随机分叉继续运行；引擎、渲染、黄金基线和回放未改动。

## 本地验证

- Node 22：原有 125 项模拟用例、16 项解谜测试、常规黄金快照 35 项及完整黄金快照 45 项。

- 单文件已检查关卡和 schema 均内联。浏览器全量复测 131/131，独立编辑器脚本通过；369×200 网格的电火花专项也已通过。

## 读档复查

- 在浏览器复现了终局恢复后管理器仍显示进行中，以及阶段错误的存档会丢弃当前局面的情况。
- 解谜现在先在临时世界完成校验和回放，再切换模式。恢复胜局与败局都会在进入事件后同步结算。编辑器可以打开初始结构需要修正的草稿，试播报错后继续修改。
- 浏览器回归另覆盖坏档不替换世界、结算事件顺序、失败试播保留表单，以及使用官方 id 的自制关不会解锁下一关。
