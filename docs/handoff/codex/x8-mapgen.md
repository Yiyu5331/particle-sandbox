# X8 程序生成地图

2026-11-20，Codex。在从 main 的 0f4bd8e 建立的独立工作树中开发，分支为 codex/x8-mapgen。

## 已完成

- `src/gen/index.js` 提供 generateMap。八种群系与守护、文明、生态三种预设共用确定性的整数噪声与独立 xorshift32。
- 输出包含公开命令、村庄、淡水源、三向的洪水/熔岩起点以及可复现的元数据。默认沙盒可从菜单打开地图生成器，单文件可离线使用。
- 守护生成时检查几何约束；验收工具还会从实际命令重建地图，并运行物理检查。独立的缩略图页面可对当前种子执行相同检查。
- [MAPGEN.md](../../MAPGEN.md) 记录参数、阈值、回放方式、增加群系的步骤和实测数据。

## 决策

- 这是侧视重力世界，出生方向取左、右和上空。熔岩的侧向出露口比洪水更靠近坡脚；底部保留完整基岩。
- W 对应 villageWidth，附近水源按到村庄矩形的欧氏距离判断。坡道按实际连续空格和支撑面检查，允许种子落在坡面上，但仍须能一路向村庄下行。
- 生成耗时与 300 步稳定性分开测量。稳定性观察实际发生的液体移动、腾空、坍塌以及结束时的原岩和区域；原位凝固单独识别。

## 验证

- 两组尺寸各覆盖八个群系、每群系 1000 个种子，16,000 张守护地图全部通过。固定 422×246 组单独为 8000/8000。
- 422×246 的 480 次 Node 生成中位 0.33ms、最慢 5.48ms。注入测试中六个灾难源均能把对应材料送到村庄。
- 24 个跨宿主用例的完整输出在 Node、Chrome 与 JavaScriptCore 一致；实际世界的初始及 300 步哈希也在 Node 与 Chrome 匹配。
- Node 模拟测试 125/125、地图测试 10/10、完整引擎黄金快照 45/45。引擎、渲染器、黄金与回放文件均无差异。

- Chrome 全量自测在项目默认的 220×140 模拟网格上 132/132 通过。在额外的 220×139 网格上，水体休眠和刚体炸药两项旧用例失败；相同网格在干净 main 的 Node 测试中也复现，原测试和物理行为保留。
