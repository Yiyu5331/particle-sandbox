# 引擎接口需求

`src/engine/` 和 `src/render/` 只由维护引擎的一方修改（见 AGENTS.md）。做模式、实体、UI 时缺接口，就在这里提需求，**不要**自己改引擎，也不要绕过 `src/engine/index.js` 去 import 引擎内部文件。

## 怎么提

在下面「待处理」里按模板加一节，提交到你的分支，并在交接说明里提到它。引擎一方实现后把它移到「已完成」，写上实现的版本和接口名。

```md
### <一句话标题>
- 提出：<谁 / 哪个分支>，<日期>
- 用在：<哪个模式、什么功能>
- 现在的做法和问题：<现在怎么凑合的，为什么不够（性能？做不到？不确定性？）>
- 希望的接口：<函数签名 / 命令名 / 事件字段，越具体越好>
- 确定性要求：<会不会改变模拟结果？只读接口通常不会；改模拟的需求要说明能不能接受黄金快照重录>
- 性能预算：<每步调用几次、数据量多大>
```
